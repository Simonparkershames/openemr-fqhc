Accessibility

Every foreground/background pairing the components actually use, measured against WCAG 2.1 from the token values in tokens.css. AA is the bar: 4.5:1 for normal text, 3:1 for large text (18pt+, or 14pt bold). A pairing that fails here is a bug in the palette.
